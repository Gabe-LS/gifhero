gifhero benchmark

visual quality comparison — drop GIFs or load benchmark results

How to use

1. Run npm run bench:setup then npm run bench to generate reference GIFs.
2. Drop your gifhero output GIF on the left panel, and a reference GIF (gifski, ffmpeg) on the right.
3. Use the frame scrubber to step through and compare frame by frame.
4. Or load test/bench/results/latest.json to see the full metrics table.
